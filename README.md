- Intro, What is API/FastAPI, FastAPI vs Flask vs Django
- Setup, virtual environment, Hello World, Swagger docs
- Routes, path params, query params
- Request body, Pydantic validation, nested models
- To-Do CRUD project (GET, POST, PUT, DELETE)
- Response models, hiding sensitive data

### 🗄️ Session 2 — DB + Auth
- Status codes, custom responses, global error handling
- Dependency Injection, Middleware
- DB integration, SQLAlchemy ORM
- CRUD API with database
- Async/Await
- JWT auth, OAuth2, password hashing
- File uploads, static files

### 🚀 Session 3 — Production + Project
- CORS, environment variables
- Pytest for API testing
- Third-party API integration, web crawling
- Pagination, caching, rate limiting
- Deployment to Render
- Real-world Blog API project
